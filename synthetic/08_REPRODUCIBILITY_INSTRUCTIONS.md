# Reproducibility Instructions

All scripts are seeded (`SEED = 42` throughout) and deterministic given the same package
versions. Run from the project root (`crystal_growth_ml/`), in order — each script depends on
the previous one's output.

## 0. Environment

```bash
cd crystal_growth_ml
python3 -m pip install -r requirements.txt --break-system-packages   # or use a venv
# Core requirement: numpy, pandas, scikit-learn, scipy, matplotlib. XGBoost is OPTIONAL and
# auto-detected: if `import xgboost` succeeds, it is included in 06_ml_evaluation.py; if not,
# it is cleanly skipped (see the script's own printed message) -- no substitute is used.
```

## 1. Dataset analysis

```bash
python3 synthetic/01_dataset_analysis.py
```
Reads `data/Table.csv` (the original 96-row dataset — unchanged by this project). Writes
`synthetic/results/dataset_analysis.json`. No randomness; fully deterministic.

## 2. Methodology selection

`synthetic/02_METHODOLOGY_SELECTION.md` is a written document, not a script — it records the
comparison of the 5 candidate generation methods and the justification for the one selected.

## 3. Leakage-safe split of the original data

```bash
python3 synthetic/03_split_original_data.py
```
Writes `synthetic/data/original_train.csv` (n=67), `original_val.csv` (n=14),
`original_test.csv` (n=15). Deterministic given `SEED=42`. **`original_test.csv` must never be
read by any script before `06_ml_evaluation.py`'s final-test step** — this is enforced by
convention (no other script in this pipeline reads that file) rather than by a technical
lock, so it is worth verifying with `grep -rn "original_test" synthetic/*.py` before adding
any new script.

## 4. Synthetic data generation

```bash
python3 synthetic/04_generate_synthetic_data.py 2000    # 2000 = number of synthetic rows; optional, defaults to 2000
```
Reads `synthetic/data/original_train.csv` only. Writes
`synthetic/synthetic_crystal_growth_dataset.csv`. Deterministic given `SEED=42` — rerunning
produces bit-identical output (verified: `numpy.random.default_rng(42)` is used throughout,
not the legacy global `numpy.random` state, specifically so this holds regardless of any
other script's execution order).

## 5. Synthetic data validation

```bash
python3 synthetic/05_validate_synthetic_data.py
```
Reads `data/Table.csv` and `synthetic/synthetic_crystal_growth_dataset.csv`. Writes
`synthetic/results/ks_wasserstein_tests.csv`, `correlation_comparison.csv`,
`predictive_relationship_comparison.csv`, and all `synthetic/plots/*.png` distribution/
correlation/pair plots. `synthetic/05_VALIDATION_REPORT.md` is the accompanying written
report (not regenerated automatically — update it by hand if the numbers change materially
after a rerun).

## 6. ML evaluation

```bash
python3 synthetic/06_ml_evaluation.py
```
Reads `synthetic/data/original_train.csv`, `original_val.csv`, `original_test.csv`, and
`synthetic/synthetic_crystal_growth_dataset.csv`. Writes `synthetic/results/cv_results.csv`
(all 25×3×2×{6 or 7} individual fold results), `cv_results_summary.csv` (mean±std per
target/regime/model), `final_test_results.csv` (the single untouched-test-set check), and
`gpr_prediction_intervals.csv`. Runtime: on the reference machine used for this project,
roughly 10–15 minutes total (the GaussianProcessRegressor fits, being O(n³), dominate; the
CV loop caps synthetic augmentation at 300 rows per fold for tractability — see the
`CV_SYNTH_AUGMENT_N` constant and its docstring in the script — while the final untouched-test
check uses the full synthetic set). `synthetic/06_MODEL_EVALUATION_REPORT.md` is the
accompanying written report.

## 7. All other deliverables

`synthetic/DATA_DICTIONARY.md`, `synthetic/07_ASSUMPTIONS_AND_LIMITATIONS.md`, this file, and
`synthetic/09_METHODOLOGY_SECTION.md` (research-paper-ready) are written documents, produced
once from the outputs of steps 1–6 above; they are not regenerated by a script, since they
contain narrative interpretation, not just recomputed numbers. If steps 1–6 are rerun with
different data or a different seed, these documents should be reviewed for consistency with
the new numbers before being reused.

## Full one-shot reproduction

```bash
cd crystal_growth_ml
python3 synthetic/01_dataset_analysis.py
python3 synthetic/03_split_original_data.py
python3 synthetic/04_generate_synthetic_data.py 2000
python3 synthetic/05_validate_synthetic_data.py
python3 synthetic/06_ml_evaluation.py
```

## Determinism notes

- `SEED = 42` is used in every script, both for `numpy.random.default_rng(SEED)` (generation,
  validation sampling) and for every scikit-learn `random_state=SEED` (splits, model fits,
  cross-validation).
- Exact floating-point results can still differ across scikit-learn/numpy/scipy versions or
  hardware (BLAS backend) even with a fixed seed — this is a standard, unavoidable caveat of
  numerical reproducibility, not specific to this project. Package versions used to produce
  the delivered results are pinned in `requirements.txt`.
