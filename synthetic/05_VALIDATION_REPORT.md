# Synthetic Data Validation Report

Generated by `synthetic/05_validate_synthetic_data.py`. Compares `synthetic_crystal_growth_dataset.csv`
(n=2000) against the full original `data/Table.csv` (n=96).

> **This report checks statistical similarity only. It is not, and cannot be, proof of
> physical validity.** A synthetic dataset can look statistically like the original sample
> while still not reflecting genuine CrysMAS simulation output at unsampled points — the only
> way to confirm that would be to actually run CrysMAS at those points, which this project
> does not do. Every claim below is scoped to "statistically similar to the 96-row sample,"
> never to "physically correct."

## 1. Kolmogorov–Smirnov tests and Wasserstein distance

Full table: `synthetic/results/ks_wasserstein_tests.csv`.

| Column | KS stat | KS p-value | Reject "same distribution" @0.05 | Wasserstein (norm. by orig. std) |
|---|---|---|---|---|
| T1 (K) | 0.500 | <0.001 | **Yes** | 0.495 |
| T2 (K) | 0.375 | <0.001 | **Yes** | 0.357 |
| T3 (K) | 0.375 | <0.001 | **Yes** | 0.357 |
| T4 (K) | 0.333 | <0.001 | **Yes** | 0.346 |
| T5 (K) | 0.500 | <0.001 | **Yes** | 0.499 |
| Lc (m) | 0.097 | 0.334 | No | 0.239 |
| Le (m) | 0.084 | 0.505 | No | 0.209 |
| P (m) | 0.096 | 0.347 | No | 0.228 |
| D (m) | 0.123 | 0.115 | No | 0.216 |

**Inputs (T1–T5) intentionally fail the KS test — this is by design, stated honestly rather
than hidden.** The original T1–T5 are a small discrete factorial DOE (2–3 fixed levels per
heater); the synthetic generator samples T1–T5 *continuously* within the observed ranges (see
`02_METHODOLOGY_SELECTION.md`) so that synthetic rows are not just re-draws of the 96 original
design points. A discrete-level empirical distribution will never KS-match a continuous
uniform one, regardless of how well the generator otherwise works — this is an expected,
mechanical consequence of the design choice, not a generation defect.

**Outputs (Lc, Le, P, D) pass the KS test** (fail to reject "same distribution" at α=0.05):
their empirical distributions are statistically indistinguishable from the original sample by
this test, at this sample size.

## 2. Correlation structure

See `synthetic/plots/correlation_comparison.png` (original / synthetic / absolute-difference
heatmaps) and `synthetic/results/correlation_comparison.csv` (full pairwise table, sorted by
divergence). The largest correlation differences all involve `D (m)`:

| Pair | \|Δr\| |
|---|---|
| D – Le | 0.425 |
| D – P | 0.349 |
| D – T2 | 0.337 |
| D – Lc | 0.280 |
| D – T3 | 0.173 |
| D – T4 | 0.119 |

Every other pairwise correlation (all input–input pairs, and Lc/Le/P's correlations with
T1–T5 and each other) diverges by well under 0.05. This is the clearest, most consistent
signal across this whole validation: **the synthetic generator preserves the Lc/Le/P
correlation structure closely, and visibly degrades D's correlation structure** — exactly
what was predicted in `01_DATASET_ANALYSIS_REPORT.md` and `02_METHODOLOGY_SELECTION.md` from
D's weaker underlying GPR fit and its status as a difference of two collinear quantities. This
is not a new finding; it is the same known limitation showing up, now quantified a second,
independent way.

`synthetic/plots/distribution_comparison_<column>.png` (one per column) and

## 4. Duplicate and near-duplicate detection

- Exact duplicate `(T1..T5)` rows within the synthetic set: **0**.
- Synthetic rows within a tight normalized distance (0.05) of any original `(T1..T5)` row:
  **0**.
- Synthetic rows within a looser normalized distance (0.2) of any original row: **0**.

No synthetic row is a copy or near-copy of an original design point — consistent with the
project's explicit prohibition on "blindly duplicating or randomly perturbing" the original
data.

## 5. Outlier analysis (against the original data's own IQR fences)

| Column | Synthetic rows outside original IQR fences (of 2000) |
|---|---|
| Lc (m) | 0 |
| Le (m) | 2 |
| P (m) | 2 |
| D (m) | **37** |

`D`'s elevated outlier count (1.85% of synthetic rows) is the same pattern surfacing a third
time: `D`'s propagated uncertainty is wide enough that some generated values fall outside the
narrow range the 96 original rows happened to cover. These rows are **not removed** — an IQR
fence computed from 96 points is not a hard physical bound, and removing them would
understate `D`'s genuine uncertainty rather than report it honestly. They are flagged here so
a downstream user can filter them if their use case requires it.

## 6. Predictive-relationship comparison

A simple standardized linear model (`T1..T5 → target`) was fit separately on the original data
and on the synthetic data, for each of Lc, Le, D. **15/15 coefficients (5 features × 3
targets) had the same sign** in both fits — the direction and relative ranking of each
heater's effect is preserved. Full table: `synthetic/results/predictive_relationship_comparison.csv`.
This is a coarse, transparent check (a plain linear model, not a black box) offered as
directional evidence that the generator did not invert or scramble any input–output
relationship — it is not a claim that the synthetic data reproduces the true nonlinear
CrysMAS response surface exactly.

## 7. Summary judgment

The synthetic dataset is **statistically similar to the original sample for Lc, Le, and P**
(KS non-rejection, small correlation deltas, no near-duplicates, preserved coefficient signs).
**D is measurably less faithfully reproduced** — still passing the KS test, but with visibly
larger correlation shifts and a higher outlier rate — which is the expected, previously-
predicted consequence of D being the weakest-modeled target in this project's own validated
surrogate. This assessment is entirely about statistical resemblance to a 96-row simulation
sample; it says nothing about whether either the original or the synthetic values are close to
a real physical crystal-growth furnace, which this project has never claimed to validate
experimentally.
